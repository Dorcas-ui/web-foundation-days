About QuickNotes

QuickNotes is a simple notes app for jotting down ideas, tasks and reminders as they come to you. It is built to be fast and distraction-free, so you can spend less time organising and more time thinking.

How to use QuickNotes

  1. Open QuickNotes and click the "New note" button.
  2. Type a title and write your note in the text area.
  3. Save the note to add it to your list.
  4. Click any saved note to edit or delete it.

Features

  • Create notes instantly
  • Edit and delete notes
  • Search through all your notes
  • Clean, distraction-free interface

Keyboard shortcuts

Shortcut Action
Ctrl + N Create a new note
Ctrl + S Save the current note
Ctrl + F Search notes
